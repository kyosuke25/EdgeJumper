# EdgeJumper（ギリジャン!）

2013年のAndroidゲームをAPKに残っていたHTML・JavaScriptから復元した、オフラインで遊べるブラウザ版です。

1. このリポジトリをダウンロードして展開し、index.html をブラウザで開きます。
2. STARTを押し、足場の端に近づいたらクリック・タップ・Spaceでジャンプします。端に近いほど高得点です。

自己ベストはブラウザ内に保存します。旧版のオンラインランキング、Twitter連携、分析機能は含みません。ビルドや外部サービスは不要です。
